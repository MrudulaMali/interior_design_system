# Interior Finder System 🏡✨

A full-stack web application built with Next.js, React, TypeScript, and Tailwind CSS.

## 🚀 Overview

Interior Finder System helps users discover, browse, and connect with interior design concepts, designers, and home decor inspirations.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** TypeScript / JavaScript
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **UI & Components:** React 19

## 📦 Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### 3. Build for production

```bash
npm run build
npm run start
```
